TIC TAC TOE GAME

-->Description: <BR>
  - This project is a tic-tac-toe game developed with HTML, JavaScript, and CSS3. It allows the user to play against the computer on a 3x3 grid, incorporating logic to control turns, evaluate victory conditions, and manage the game state. It includes New Game and Reset buttons for efficient game control, as well as a win counter that records the number of victories achieved by the player.

<HR>


-->Features:<BR>
  - Player vs Computer Gameplay: Play the classic game of tic-tac-toe against the computer on a 3x3 board.<BR>

  - Automatic Game Start: The game loads directly into the interface, allowing players to start playing immediately.<BR>

  - Random Moves: The computer randomly selects available cells using JavaScript logic to simulate an opponent.<BR>

  - Win Detection Logic: JavaScript logic evaluates all possible winning combinations (rows, columns, and diagonals) to determine the winner.<BR>

  - Tie Detection: The system detects when all cells are filled without a winner and declares a tie.<BR>

  - Score Tracking System: Each player's wins and tie results are stored using localStorage, allowing statistics to be maintained between games.<BR>

  - New Game Button: Clears the board and starts a new round, preserving the score history.<BR>

  - Reset Button: Resets the entire game, erasing stored statistics and reloading the application.<BR>

  - Dynamic game board: The board is built with nine HTML cells that are dynamically updated using JavaScript and DOM manipulation.
